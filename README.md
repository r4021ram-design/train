# 🚆 RailOne Tatkal Pro — Command Center & Master Guide

A mission-control companion dashboard for Indian Railways (IRCTC / RailOne) Tatkal ticket bookings. Built with React 18, Vite, TypeScript, and Tailwind CSS.

---

## ⚡ Core Capabilities

- **Atomic Millisecond IST Clock**: Sub-second synchronized Indian Standard Time ticker (with manual IRCTC latency calibration).
- **Multi-Day Origin Trap Engine**: Calculates the exact Tatkal opening date based on train departure station rather than your boarding station.
- **1-Tap Speed Vault**: 1-click clipboard launcher for primary/secondary UPI IDs and emergency passenger details.
- **Interactive 4-Tap Reflex Drill**: Gamified practice simulator to build muscle memory for checkout taps before the real rush.
- **Comprehensive Master Guide**: In-app reader covering AC vs Non-AC quotas, Master List rules, and dual-device payment strategies.
- **Fullscreen Terminal View**: Edge-to-edge desktop command center display.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
